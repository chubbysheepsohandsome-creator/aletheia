ALETHEIA Tools · Writing Process

See how a Word file was written.

Word quietly records when a document was opened, saved and edited. This page reads that record from a .docx file and explains it in plain language. It is not an AI detector and cannot prove who wrote anything; it gives you something concrete to talk about with the writer.

05 · Formatting and source clues

Fonts, sizes, languages and hidden text

Text typed straight into a document usually shares one font, size and spelling language. Text pasted from a website, PDF or another file often keeps its own formatting. A mismatch is a clue to ask about, not proof of copying.
